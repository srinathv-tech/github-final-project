# Simple Interest Calculator

A Bash script that calculates simple interest from user input.

## Description

`simple-interest.sh` prompts the user for the principal amount, the rate of
interest (% per annum), and the time period (in years), then calculates and
displays the simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

## Example

```
Enter the principal amount: 10000
Enter the rate of interest (%): 5
Enter the time period (years): 2
Simple Interest = 1000.00
```
